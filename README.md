## 🌟 О проекте

**NijiPanel** — автономный пульт управления инфраструктурой любого масштаба.
* **Agentless-архитектура:** Работает исключительно по стандартному защищенному протоколу **SSH**. Никаких фоновых агентов, демонов, открытых лишних портов или сторонних бинарников на целевых машинах не требуется.
* **Дизайн Нидзики Идзити:** Фирменная палитра **Dorito Yellow** (`#ffd100`), глубокий темный фон **Carbon Dark** (`#0d0e12`) и строгая эстетика **IBM Carbon Design System**.
* **Все в одном контейнере:** Один легковесный контейнер или бинарник включает в себя и backend API, и полнофункциональный frontend SPA.

## ⚡ Ключевые возможности

### 🚀 1. Интерактивный онбординг и управление флотом
* **Быстрый старт за 4 шага (Setup Wizard):** Автоматический мастер первого запуска для настройки мастер-ключа, подключения первого сервера и выбора начального стека утилит.
* **🌐 Инспектор сетевой топологии & GeoIP:**
  * Определение публичного IP, провайдера/хостинга (ISP/ASN), страны, города и координат.
  * Автоматический расчет CIDR-подсетей, масок, broadcast и точных диапазонов доступных IP-адресов.
  * Инспекция всех физических и виртуальных интерфейсов (`eth0`, `docker0`, bridges, veth).
* **Случайный высокий SSH-порт (Hardening):** Автоматическая безопасная смена порта SSH на случайный высокий диапазон (20000–59000) с проверкой конфигурации и открытием в UFW.
* **Масштабируемое дерево серверов (Resizable Tree Sidebar):**
  * Иерархическое дерево хостов с регулируемой шириной панели (200px – 460px) с сохранением в памяти.
  * Мгновенное переключение между серверами в 1 клик.

### 💻 2. Многосессионный Web-терминал (Multi-Session PTY)
* **Вкладки терминалов:** Открывайте неограниченное количество параллельных SSH-сессий во вкладках с возможностью переименования.
* **Защита от выгрузки вкладок:** Кольцевой буфер сессий держит PTY активным на бэкенде. При сворачивании или перезагрузке браузера на телефоне или ПК сессия и запущенные процессы (`htop`, сборка) не сбрасываются.

### 🐳 3. Экосистема Docker & 1-Click App Store
* **1-Click App Store:** Каталог из 30+ популярных шаблонов приложений (PostgreSQL, Redis, Nextcloud, Vaultwarden, Uptime Kuma, Plausible, Gitea, Grafana, Portainer, Meilisearch и др.) с настройкой переменных окружения и автоматическим развертыванием Compose.
* **Поиск по Docker Hub:** Встроенный поиск образов прямо из панели с выводом количества звезд и тегов.
* **Visual Compose Studio:** Визуализация сервисов, портов и томов, редактор Monaco, валидация через `docker compose config --dry-run`.
* **Crash Watchdog & OOM-Killed Detector:** Автоматическое обнаружение упавших контейнеров (ExitCode 137, OOM), статус-бейджи и просмотр краш-дампов логов.
* **Smart Docker Prune:** Очистка неиспользуемых образов, контейнеров и билд-кэша с предварительным расчетом освобождаемого места.
* **Docker Exec терминал:** Прямой запуск веб-терминала внутри любого контейнера.

### ⚙️ 4. Централизованный реестр команд (`commands.json`)
* **Никаких захардкоженных bash-строк:** Все 56 системных команд платформы вынесены в `commands.json` и таблицу `command_templates` в SQLite.
* **Инлайн-редактор в настройках:** Поиск, фильтры по категориям (`System`, `Network`, `Docker`, `Systemd`, `Users`, `Packages`, `Firewall`, `Cron`, `Files`), редактирование bash-кода, изменение таймаутов, бейджи `CUSTOMIZED` и сброс к дефолтным значениям.

### 🛠️ 5. Системное администрирование (SysAdmin Cockpit)
* **Systemd Services Cockpit:** Мониторинг всех системных служб, фильтры (Running, Failed), управление (`start`, `stop`, `restart`, `enable`, `disable`) и живой просмотр логов `journalctl`.
* **Менеджер пользователей Linux:** Просмотр пользователей, создание, блокировка/разблокировка (`passwd -l`), выдача и отзыв прав `sudo`.
* **Обновления пакетов ОС (APT / DNF):** Проверка доступных пакетов безопасности и 1-click безопасный апгрейд.
* **Firewall Sentinel:** Управление правилами UFW / iptables и модуль **Fail2ban** со списком заблокированных IP и разбаном в 1 клик.
* **Crontab менеджер:** Управление расписанием задач Cron с безопасной установкой через base64.
* **Live Socket Inspector:** Инспекция открытых портов и процессов (`ss -tulpn`) и генератор CLI-команд для SSH-туннелей.

### 📂 6. Файловый менеджер & Хранилище
* **SFTP проводник:** Загрузка, скачивание, создание файлов и папок, права доступа.
* **Monaco Editor + Diff Viewer:** Редактирование файлов с подсветкой синтаксиса и режимом сравнения изменений перед сохранением.
* **Smart Disk Treemap:** Визуализация занятого дискового пространства с настраиваемыми исключениями (`/proc`, `/sys`, `/mnt`).
* **Архивация на сервере:** Сжатие и распаковка `.zip`, `.tar.gz`, `.tar.bz2` прямо на стороне сервера.
* **Публичные ссылки (File Sharing):** Генерация ссылок для прямого скачивания файлов с серверов с настройкой срока жизни (TTL), лимита скачиваний (включая одноразовые burn-after-reading) и пароля.
* **Прямая синхронизация между серверами:** Перенос файлов с сервера на сервер через прямой `rsync`/`scp` без проксирования через браузер.

### 📊 7. Мониторинг, алерты и безопасность
* **Beszel-style графики:** Плавные sparkline-графики CPU, RAM, Network I/O и предиктивный прогноз заполнения диска (Disk Fill Prediction).
* **Центр уведомлений:** Внутренний журнал алертов + отправка критических уведомлений в **Telegram** и по **Webhook**.
* **Аппаратный бенчмарк:** Неразрушающий замер скорости CPU (SHA-256), диска (прямая запись) и задержки сети с расчетом Health Score (0-100).
* **Passkeys (WebAuthn):** Вход без пароля через Touch ID, Face ID, Windows Hello или YubiKey.
* **Шифрование данных:** Все пароли и SSH-ключи шифруются алгоритмом **AES-256-GCM**, пароли хэшируются с солью через **PBKDF2**.

## 🚀 Быстрый запуск (Docker)

### Вариант 1: Docker Compose (Рекомендуется)

Создайте файл `docker-compose.yml`:

```yaml
services:
  nijipanel:
    image: ghcr.io/perdub/nijipanel:latest
    container_name: nijipanel
    restart: unless-stopped
    ports:
      - "8080:8080"
    volumes:
      - ./nijipanel_data:/data
    environment:
      - ASPNETCORE_ENVIRONMENT=Production
      - ASPNETCORE_URLS=http://+:8080
      - DATABASE_PATH=/data/nijipanel.db
```

Запустите панель:
```bash
docker compose up -d
```
Панель доступна по адресу: **`http://localhost:8080`**.

---

### Вариант 2: Docker CLI

```bash
docker run -d \
  --name nijipanel \
  --restart unless-stopped \

  -v $(pwd)/nijipanel_data:/data \
```

## 💻 Локальная разработка

Требования:
* **.NET 10 SDK**
* **Node.js 22+**

### 1. Сборка фронтенда:
```bash
cd src/ServerDeck.Frontend
npm install
npm run build
```
Статический бандл автоматически компилируется в `src/ServerDeck.Backend/wwwroot`.

### 2. Запуск бэкенда:
```bash
cd src/ServerDeck.Backend
dotnet run
```
Сервер запустится на `http://localhost:5000` (или `http://localhost:8080`).

## 🔒 Безопасность и архитектура

* Все секреты и учетные данные серверов зашифрованы с использованием **AES-256-GCM** (96-битный nonce, 128-битный auth tag).
* Мастер-пароль администратора защищен **PBKDF2 (SHA-256, 100 000 итераций)** с уникальной солью на пользователя.
* Сессии защищены **JWT** токенами с автоматически ротируемым криптографическим ключом подписи.
* Поддержка двухфакторной / беспарольной биометрической аутентификации **Passkeys (FIDO2 / WebAuthn)**.
