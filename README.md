# NijiPanel 🥁✨ (Nijika Edition)

**NijiPanel** — быстрая, функциональная и легковесная панель управления серверами на базе **.NET 10** и **React**.
Оформлена в ярком стиле **Нидзики Идзити** (Dorito Yellow + Carbon Dark) и вдохновлена **IBM Carbon Design System**.
Архитектура **Agentless** — управление серверами осуществляется исключительно по **SSH**, без установки сторонних агентов и демонов на целевые машины. Панель упакована в **один Docker-контейнер** или один автономный бинарник.

---

## ⚡ Ключевые возможности

* **🌐 Мультихостовость (Agentless):** Управляйте любым количеством VPS и выделенных серверов. Подключение по SSH (пароль, индивидуальный SSH-ключ или встроенный глобальный мастер-ключ).
* **🐳 Docker & Контейнеры:**
  * Просмотр состояния всех контейнеров, статусы, открытые порты, образы.
  * Управление: запуск (`start`), остановка (`stop`), перезапуск (`restart`), удаление (`rm`).
  * Realtime просмотр логов (`docker logs`).
  * Полная инспекция томов (`Mounts`), переменных окружения (`ENV`) и сетевых настроек.
* **📦 Docker Compose стеки:**
  * Автоматический поиск Compose-проектов на сервере (`/opt`, `/home`, `/root`, `/var/www`).
  * Управление стеками в 1 клик: `compose up -d`, `down`, `restart`, `pull`, просмотр логов стека.
  * Прямой переход к редактированию `docker-compose.yml` в редакторе Monaco.
* **📂 SFTP Файловый менеджер & Monaco Editor:**
  * Проводник по всей файловой системе сервера (хлебные крошки, права `chmod`, быстрые переходы `/opt`, `/etc`).
  * Встроенный **Monaco Editor** (движок VS Code) с подсветкой синтаксиса для `.env`, конфигураций, скриптов и сохранением по `Ctrl+S`.
  * **Медиа-просмотрщик:** превью картинок (PNG, JPG, WebP, SVG) и воспроизведение аудио (MP3, WAV, OGG) прямо через SFTP-стриминг.
  * Загрузка и скачивание файлов, создание папок и файлов.
* **💻 Несбрасываемый Web-терминал (Persistent PTY):**
  * Полноценная консоль на базе `xterm.js`.
  * **Защита от выгрузки мобильных вкладок:** Бэкенд держит PTY-сессию активной в кольцевом буфере. Если мобильный браузер свернуть или выгрузить вкладку, при возвращении сессия мгновенно восстанавливается без прерывания запущенных процессов!
* **📊 Живые дашборды ресурсов:**
  * Загрузка процессора (CPU %)
  * Использование оперативной памяти (RAM использовано / всего в GB и %)
  * Дисковое пространство (Root partition использовано / всего и %)
  * **Использование сетевого канала (RX/TX переданный трафик в GB)**
  * Load Average и Uptime сервера
  * Статус установленного демона Docker
* **🔌 SSH Keepalive (без самопроизвольных дисконнектов):**
  * Встроенный пинг сессий каждые 15 секунд — соединение не рвется даже при длительном простое или через капризные NAT/VPN.
* **⚡ Настройка сервера в 1 клик (One-liner command):**
  * Генерация одной готовой команды для консоли сервера (`mkdir -p ~/.ssh && echo '...' >> ~/.ssh/authorized_keys`), которая настраивает доступ панели за 2 секунды.
* **📝 Реестр портов & Заметки:**
  * Удобная таблица «Какой порт за что отвечает» (например, `3000: Grafana`, `5432: Postgres`), чтобы никогда не путаться в назначении портов.
  * Заметки и инструкции по каждому серверу с быстрым сохранением.
* **🔀 SSH Проброс портов (Туннели):**
  * Проброс удаленных портов (БД, веб-интерфейсы внутренних сервисов) на локальный порт панели.
* **🔄 Прямой перенос файлов между серверами (Direct Server-to-Server Sync):**
  * Виртуальный буфер обмена в проводнике файлов: нажмите «Копировать» на Сервере 1, перейдите в папку Сервера 2 и нажмите «Вставить».
  * **Прямая перекачка:** Передача идёт **напрямую между серверами** через `rsync`/`scp` без проксирования через панель и без лишнего расхода трафика панели.
* **☁️ Облачный бэкап и переезд в «2 значения» (Zero-Knowledge):**
  * Вся инфраструктура (серверы, ключи, порты, настройки) шифруется надежным алгоритмом **AES-256-GCM**.
  * Зашифрованный блоб выгружается в облако, а панель выдает всего **2 строчки**: **Код обмена / URL** и **Пароль расшифровки**.
  * На любом новом сервере просто введите эти 2 значения — и панель моментально восстановит всё.
  * Также доступен офлайн экспорт/импорт файла `.deck`.
* **🛠️ Встроенные утилиты (Utils):**
  * Генератор надежных паролей с настройкой длины, цифр и спецсимволов.
  * Генератор пар SSH-ключей (RSA 4096) со скачиванием `.pub` и приватного ключа.

## 🚀 Быстрый запуск (Docker)

### Вариант 1: Docker Compose (Рекомендуется)
```bash
docker compose up -d
```
Панель будет доступна по адресу: `http://localhost:8080`.

### Вариант 2: Docker CLI
```bash
docker run -d \
  --name serverdeck \
  --restart unless-stopped \
  -p 8080:8080 \
  -v $(pwd)/serverdeck_data:/data \
  serverdeck:latest
```

## 💻 Локальный запуск для разработки

Требования:
* **.NET 10 SDK**
* **Node.js 22+**

### 1. Запуск Backend:
```bash
cd src/ServerDeck.Backend
dotnet run
```
Бэкенд запустится на `http://localhost:5000`. База данных SQLite автоматически создастся в `data/servers.db`.

### 2. Запуск Frontend (Vite Dev Server):
```bash
cd src/ServerDeck.Frontend
npm install
npm run dev
```
Фронтенд запустится на `http://localhost:3000` и будет автоматически проксировать API и WebSockets в бэкенд.

### 3. Сборка фронтенда в статику бэкенда:
```bash
cd src/ServerDeck.Frontend
npm run build
```
Собранные файлы автоматически попадут в `src/ServerDeck.Backend/wwwroot`. После этого бэкенд отдает и API, и интерфейс в одиночку.

## 🔒 Безопасность

* Учетные данные серверов (пароли и приватные SSH-ключи) шифруются алгоритмом **AES-256-GCM** с 96-битным nonce и 128-битным auth tag.
* Мастер-пароль администратора хэшируется с использованием **PBKDF2 (SHA-256, 100 000 итераций)** с уникальной криптографической солью.
* Все сессии терминала защищены токенами авторизации.
* Поддерживается смена мастер-ключа панели и пароля администратора в настройках безопасности.
