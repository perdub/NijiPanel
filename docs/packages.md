# 📦 OS Package Updates

Своевременная установка обновлений безопасности — краеугольный камень защиты Linux-инфраструктуры. Модуль **OS Package Updates** автоматизирует аудит и обновление пакетов на любых дистрибутивах.

---

## 🐧 1. Поддержка дистрибутивов

NijiPanel автоматически определяет установленный в системе пакетный менеджер:

| Дистрибутив | Пакетный менеджер | Команда проверки | Команда обновления |
| :--- | :--- | :--- | :--- |
| **Ubuntu / Debian** | `APT` | `apt-get update && apt-get --just-print upgrade` | `DEBIAN_FRONTEND=noninteractive apt-get upgrade -y` |
| **RHEL / Alma / Rocky / Fedora** | `DNF` / `YUM` | `dnf check-update --security` | `dnf upgrade --security -y` |
| **Arch Linux** | `Pacman` | `checkupdates` | `pacman -Syu --noconfirm` |
| **Alpine Linux** | `APK` | `apk update && apk version -l '<'` | `apk upgrade` |

---

## 🔍 2. Проверка обновлений (Check Updates)

Клик по кнопке **«Check Updates»** запускает безопасный аудит без внесения изменений в систему:

* **Индикатор безопасности:** количество обнаруженных патчей безопасности (Security Advisories).
* **Список пакетов:**
  * Название пакета (например, `openssl`, `linux-image-generic`, `curl`).
  * Текущая установленная версия в системе.
  * Новая доступная версия в репозитории.
  * Флаг критичности (Security / Standard).

---

## 🚀 3. Фоновый апгрейд в 1 клик (Upgrade Packages)

* **Неинтерактивное выполнение:** команды запускаются с флагами автоматического принятия (`-y`, `--noconfirm`) и подавлением интерактивных диалогов debconf/dpkg, исключая зависание процесса.
* **Таймауты и логирование:** процесс апгрейда транслирует лог выполнения в реальном времени, позволяя отслеживать загрузку и установку пакетов.
* **Автоматическая ре-валидация:** после завершения обновления панель повторно запрашивает статус хоста и подтверждает нулевой остаток ожидающих обновлений.
