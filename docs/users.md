# 👥 Linux Users & Groups

Модуль управления учетными записями Linux предоставляет администратору безопасный интерфейс для аудита и настройки пользователей операционной системы без необходимости прямого редактирования `/etc/passwd` и `/etc/shadow`.

---

## 📋 1. Инвентарь учетных записей

Панель автоматически анализирует пользователей целевого хоста и группирует их по статусу:

* **Имя пользователя (Username):** имя учетной записи.
* **Идентификаторы UID и GID:** цифровые идентификаторы пользователя и основной группы.
* **Домашний каталог (Home Directory):** путь к домашней папке (например, `/home/alex` или `/root`).
* **Командная оболочка (Default Shell):** `/bin/bash`, `/bin/zsh`, `/bin/sh` или `/usr/sbin/nologin` (для сервисных аккаунтов).
* **Права суперпользователя (Sudo Status):** золотистый бейдж `SUDO` для пользователей, входящих в привилегированные группы (`sudo`, `wheel`).
* **Статус блокировки (Lock Status):** индикатор `LOCKED` для заблокированных аккаунтов.

---

## ➕ 2. Создание новой учетной записи

Диалог добавления пользователя позволяет настроить все параметры в одной форме:

1. **Username:** имя нового пользователя (проверяется на корректность Unix-имен).
2. **Пароль (опционально):** надежный пароль или возможность оставить аккаунт доступным только по SSH-ключам.
3. **Выбор Shell:** выбор командной оболочки из обнаруженных в системе.
4. **Флаг Sudo Privileges:** автоматическое включение пользователя в группу `sudo` / `wheel` для выполнения команд администратора.
5. **Флаг Create Home Directory:** автоматическое создание домашнего каталога (`/home/<username>`) с копированием базовых файлов окружения из `/etc/skel`.

---

## 🔒 3. Блокировка и права доступа

Для каждого пользователя доступны быстрые действия:

* **Lock / Unlock Account:**  
  Блокировка пользователя через `passwd -l <username>` (добавление символа `!` в поле пароля `/etc/shadow`) и обратная разблокировка `passwd -u`. Заблокированный пользователь не сможет авторизоваться по паролю.
* **Toggle Sudo Privileges:**  
  Мгновенное добавление или отзыв привилегий суперпользователя (добавление/удаление из группы `sudo` или `wheel`).
* **Delete User:**  
  Удаление учетной записи с опциональной очисткой домашней директории (`userdel -r`). Для безопасности удаление пользователя `root` жестко заблокировано.
