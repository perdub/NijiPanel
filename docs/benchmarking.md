# 📊 Аппаратный бенчмарк

Модуль **Hardware Benchmark** позволяет быстро оценить реальную производительность хоста без установки сторонних утилит вроде Geekbench или sysbench.

---

## ⚡ Принцип неразрушающего замера (Non-Destructive)

Традиционные бенчмарки часто генерируют экстремальную нагрузку, разогревая CPU и расходуя ресурс SSD терабайтами записи. 

Бенчмарк NijiPanel спроектирован как **экспресс-тест (время выполнения ~10–15 секунд)**:
* Использует исключительно стандартные утилиты Linux (`openssl`, `dd`, `ping`).
* Пишет ровно 256 МБ данных для замера реальной скорости диска.
* Не нарушает работу запущенных production-сервисов.
* Гарантированно очищает все временные файлы через системный обработчик `trap`.

---

## 🧪 Что измеряет бенчмарк

### 1. Вычислительная мощность CPU (SHA-256 Throughput)
* Тестирует производительность криптографических инструкций ядра процессора (Intel SHA Extensions / ARMv8 Crypto).
* Запускает замер `openssl speed -seconds 2 sha256` или фолбэк с наносекундным таймингом `date +%s%N`.
* Результат: пропускная способность хэширования в **МБ/сек**.

### 2. Скорость прямой записи на диск (Disk Direct I/O)
* Для исключения влияния оперативной памяти и кэша страниц ядра Linux (Page Cache) используется флаг прямого ввода-вывода `oflag=direct`:
  ```bash
  dd if=/dev/zero of="/tmp/nijibench_test" bs=64M count=4 oflag=direct
  ```
* Если файловая система не поддерживает `oflag=direct`, выполняется безопасный фолбэк с принудительной синхронизацией буферов `conv=fdatasync`.
* Результат: реальная скорость физической записи накопителя (NVMe SSD, SATA SSD, HDD) в **МБ/сек**.

### 3. Сетевая задержка (Gateway Latency)
* Пакетный замер пинга до глобальных корневых Anycast-узлов (`1.1.1.1` Cloudflare и `8.8.8.8` Google).
* Результат: минимальный, средний и максимальный RTT в **миллисекундах (мс)**.

## 🏆 Интегральный Health Score (0–100)

По результатам трех измерений алгоритм рассчитывает суммарный балл производительности машины **Health Score**:

| Балл | Категория | Описание |
| :--- | :--- | :--- |
| **85 – 100** | 🚀 High Performance | Современный NVMe сервер с высокой частотой CPU и быстрым каналом. |
| **60 – 84** | 🟢 Standard Cloud VPS | Обычный надежный виртуальный сервер со стандартным SSD. |
| **30 – 59** | 🟡 Constrained / Shared | Сервер с перегруженным CPU (steal time) или медленным блочным диском. |
| **0 – 29** | 🔴 Critical Bottleneck | Критические задержки сети (>100мс) или деградация дисковой подсистемы. |

## 🧹 Гарантированная самоочистка (Cleanup Trap)

В начале выполнения скрипта инициализируется системный перехватчик сигналов POSIX:

```bash
TMP_BENCH="/tmp/nijibench_test"
trap 'rm -f /tmp/nijibench_* 2>/dev/null' EXIT INT TERM
```

Даже если пользователь оборвет соединение или нажмет отмену в процессе замера, временный тестовый файл будет немедленно и бесследно удален.
