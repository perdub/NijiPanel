# 🎨 Дизайн-система IBM Carbon & Nijika Theme

Эстетика NijiPanel вдохновлена синтезом строгой промышленной дизайн-системы **IBM Carbon Design System** и образом Нидзики Идзити — энергичной барабанщицы группы Kessoku Band из *Bocchi the Rock!*.

---

## ⚡ Философия визуального стиля

1. **Бескомпромиссная строгость (0px Border-Radius):**  
   Никаких мягких скруглений («bubbly cards»), pill-кнопок или сглаженных овалов. Все элементы интерфейса — карточки, инпуты, модальные окна, теги, бейджи, терминальные окна и вкладки — имеют строго **прямоугольные острые углы `border-radius: 0px`**.
2. **Глубокий угольный фон (Carbon Dark):**  
   Основной тон интерфейса — угольно-черный `#0d0e12` и темно-серый `#16171d`, создающие кинематографичный контраст и снижающие утомляемость глаз при ночной работе.
3. **Фирменный акцент Dorito Yellow (`#ffd100`):**  
   Легендарный символ «дорито-ахогэ» Нидзики переведен в яркий золотистый цвет активных состояний, фокусов, спиннеров и ключевых индикаторов.
4. **Контрастная лента Nijika Ribbon (`#f43f5e`):**  
   Вспышки рубинового цвета используются для критических алертов, упавших служб и опасных действий (удаление, принудительная остановка).

## 🔤 Типографика

* **Интерфейс и заголовки:**  
  `'IBM Plex Sans', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`  
  Шрифт передает техническую четкость, отличную читаемость на экранах любой плотности пикселей и строгую геометрию.
* **Код, консоль, IP-адреса и метрики:**  
  `'JetBrains Mono', ui-monospace, Menlo, Monaco, Consolas, monospace`  
  Моноширинный шрифт с табличными цифрами гарантирует, что списки портов, хэши, тайминги пинга и столбцы системных метрик не прыгают при обновлении значений в реальном времени.

## 🔺 Символика и логотип (Dorito Ahoge & Crossed Sticks)

Логотип NijiPanel объединяет в себе три ключевых образа:

1. **Золотистый чипс Dorito:** стилизованный треугольный локон волос Нидзики Идзити с теплой текстурой специй.
2. **Скрещенные барабанные палочки:** отражение ритмичной надежности сервера (keep the beat!).
3. **Красный бант Ribbon:** фирменный шейный аксессуар Нидзики.

```
          / \
         /   \       Crossed Drumsticks + Dorito
        /     \
       /   *   \     "The Drummer of Your Servers"
      /_________\
         \ _ /
```

Векторный SVG логотип интегрирован в шапку сайта документации, favicon и компонент `DoritoLogo.tsx` на фронтенде.

## 📐 Правило строгих 0px компонентов

В кодовой базе фронтенда действует строгий линтинг и правило стилей:

```css
/* Пример Carbon Card */
.carbon-card {
  background-color: #16171d;
  border: 1px solid #282828;
  border-radius: 0px !important;
  box-shadow: none;
}

/* Пример Carbon Button */
.carbon-btn-primary {
  background-color: #ffd100;
  color: #000000;
  font-weight: 600;
  border-radius: 0px !important;
  border: 1px solid #ffd100;
}
.carbon-btn-primary:hover {
  background-color: #ffe600;
}
```

Все индикаторы состояний реализованы через компактные прямоугольные бейджи с моноширинным шрифтом (например, `[ONLINE]`, `[RUNNING]`, `[OOM-KILLED]`, `[CUSTOMIZED]`).
