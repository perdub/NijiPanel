> **ВАЖНОЕ ТРЕБОВАНИЕ ДЛЯ ВСЕХ PULL REQUEST:**  
> Любое изменение кодовой базы, затрагивающее функционал платформы — **новый эндпоинт REST API, изменение DTO, добавление системной команды в `commands.json`, изменение логики работы модуля или переменной окружения** — **ОБЯЗАНО** сопровождаться соответствующим обновлением документации в папке `docs/` в рамках того же самого PR!

> **PR без обновления документации автоматически отклоняются и не принимаются к слиянию.**  
> Подробные инструкции и чеклист смотрите в файле [docs/CONTRIBUTING_DOCS.md](docs/CONTRIBUTING_DOCS.md).

## 🛠️ Рабочее окружение и инструменты

Для разработки вам потребуются:
* **.NET 10 SDK** (версия 10.0+)
* **Node.js 22+** и **npm**
* **Docker** и **Docker Compose**
* Редактор кода: VS Code / JetBrains Rider / Neovim

## 🌿 Процесс разработки (Git Workflow)

1. Форкните репозиторий и создайте тематическую ветку от `main`:
   ```bash
   git checkout -b feat/my-awesome-feature
   # или
   git checkout -b fix/issue-description
   ```
2. Формат коммитов (Conventional Commits):
   * `feat(...)`: новый функционал
   * `fix(...)`: исправление ошибки
   * `docs(...)`: обновление или добавление документации
   * `style(...)`: правки стилей интерфейса (с соблюдением правила 0px Carbon)
   * `refactor(...)`: рефакторинг кода без изменения логики
   * `perf(...)`: оптимизация производительности

## 🎨 Стандарты дизайна (IBM Carbon & Nijika Theme)

* **Строгое правило 0px Border-Radius:** все компоненты интерфейса (кнопки, поля ввода, карточки, модальные окна, бейджи) должны иметь острые прямоугольные углы `border-radius: 0px`.
* **Палитра:**
  * Темно-угольный фон: `#0d0e12`, `#16171d`.
  * Линии и границы: `#282828`, `#212121`.
  * Акцент Dorito Yellow: `#ffd100`.
  * Индикаторы тревоги: `#f43f5e`.
* **Типографика:** IBM Plex Sans для текста и JetBrains Mono для консоли и метрик.

## 🧪 Проверка сборки перед отправкой PR

Перед созданием Pull Request убедитесь, что сборка бэкенда, фронтенда и тесты проходят без ошибок:

```bash
# 1. Сборка фронтенда
cd src/NijiPanel.Frontend
npm install
npm run build

# 2. Сборка бэкенда
cd ../NijiPanel.Backend
dotnet build

# 3. Проверка сайта документации
cd ../../docs
python3 -m http.server 3000
```
